# Why we are here? Learning programming in an AI code generation era
In 2026, artificial intelligence can generate functional code form a single sentence or even a single word, and inproving rapidly every second.For designers, this raises a virtual question: if artificial intelligence can write code faster and more fluently, perfectly than most humans, why we still need to learn program ourselves? This essay argues that programming is no longer primarily a skill for writing code, but a critical craft for understanding and redeeming machine creativity.In an age of a automated code, human programming literacy is not obsolete, it is the only thing that preserves artistic intention and creative control.
